## 👋 About Me

I'm a **full-stack developer** from Bangladesh who builds fast, accessible and scalable web applications — from polished React interfaces to type-safe backends with production-grade databases.

- 🎨 **Front-end:** responsive UIs with **React, Next.js, TypeScript & Tailwind CSS**
- ⚙️ **Back-end:** secure REST APIs with **Node.js, Express & TypeScript**
- 🗄️ **Data:** **PostgreSQL + Prisma** for relational data, **MongoDB** for flexible schemas, **Redis** for caching
- 🔐 **Security:** authentication & authorization with **JWT** and **Firebase**
- 🐳 **Tooling:** containerized workflows with **Docker**, version control with **Git**
- 📈 Currently deepening my knowledge of system design, performance optimization and clean architecture

> 💼 **Open to front-end / full-stack opportunities.**
